# 动画与音效绑定（必须执行）

## 分镜同步设计

每个承载信息的主要动画必须安排对应音效，包括入场、运动、碰撞、切换、变化、强调、反馈与落定。不得画面完成后仅补开场、转场和结尾声。

主要动画原则上都有声音；有意静音须记录表达目的，不能遗漏后默认静音。环境微动、持续纹理和装饰性循环不必逐次发声。用户当次明确静音要求优先。

| 动画事件 | 声音设计 | 同步位置 |
|---|---|---|
| 纸张、漫画分格展开 | 展开、翻页、撕纸 | 展开过程及停止位置 |
| 物体滑入、冲出画框 | 匹配速度和材质的滑动、掠过 | 跟随运动，落定可另加短音 |
| 切断、切半 | 剪切、切断 | 切口完成瞬间 |
| 条形增长、数字变化 | 递进音或连续增长声 | 跟随变化，终值落定收束；不能每帧一响 |
| 批注、圈线、划线 | 笔触、书写 | 跟随绘制过程 |
| 符号变形、关系连接 | 变形、连接反馈与强调 | 新关系形成瞬间 |
| 物体碰撞、盖章、标题落下 | 对应材质的撞击、落定 | 接触瞬间 |
| 回收、退场 | 回收、滑动、掠过 | 跟随退场 |
| 入口、状态点亮 | 选择、确认反馈 | 状态切换瞬间 |

以上为例，不是固定音效库。同一对象保持一致的声音材质，不同动作有变化，不全片重复一个“嗖”。按实际需要组合运动、接触和反馈声，不强迫每次叠满。

## 工程绑定

动画与音效共享event_id和事件时间定义，记录镜头、动画事件、声音类型或文件、运动开始、接触／落定、结束、持续时长、音量与复核状态。尚无文件写明“素材待准备”，不伪称齐备。

从同一事件时间推导动作和声音，改变动画时声音同步移动。区分预备、运动、接触和结束，不把所有音效机械放在动画起点。

无录音时记语义锚点与预排计划，准确秒数留空；不能伪造校准帧号。剪音、变速或调镜头后统一更新字幕、动画、音效和原音→成片映射。

## 验收

逐项检查主要动画是否有声音或明确静音理由、声音是否符合动作材质。覆盖表完整不等于实际听验完成。

听看运动过程及接触、结束位置，再检查与口播的关系。接触等硬事件可用约±0.10秒作为内部检查目标，持续声与渐变不机械套用；最终以实际听看效果为准，未审听不得称同步合格。

丰富度来自动作覆盖、材质差异和节奏层次，不靠音效总数、响度或密集叠加。口播优先，通过降低音量、调整频段或错开密集事件避免掩盖，不能以人声优先为由漏做主要动作音效。

Claude负责按已确认风格选择授权适用的现成背景音乐并自动配入视频；用户已选曲优先，不强制每期等待选曲确认。记录来源、授权与署名，不擅自付费购买。人声期间以侧链/音量自动化动态压低音乐，句间可自然回升；音乐与音效一起检查，不能只压低其中一条。若须参考电平，可先试让音乐短时响度低于人声约12–18dB，再按频谱、齿音处理和实际听感调整；这不是平台标准或通过阈值。保留独立人声、音乐、音效和最终混音，检查峰值、削波、响度与手机可懂度，未听验不保证无掩盖。背景音乐不能替代动画音效，也不得复用此前明确弃用的合成候选。
