# Vibe Skills

**A collection of reusable AI skills for my own creative and project workflows.**

我自己在用的 AI Skill 合集。每个 skill 一个文件夹，可以单独安装。

## 目录 / Skills

| Skill | 作用 / What it does | 版本 |
|---|---|---|

点进各自文件夹查看详细说明和安装方法。

Open each folder for details and install steps.

## 通用安装 / General install

把需要的 skill 文件夹复制到你所用 AI 工具的 skills 目录，例如 Claude Code 的 `~/.claude/skills/`：

```bash
git clone https://github.com/wyx062102-dotcom/vibe-skills.git
cp -r vibe-skills/<skill 文件夹名> ~/.claude/skills/
```

在 Claude 应用里，也可以把 skill 文件夹打包成 zip，在 设置 → Skills 里上传。
